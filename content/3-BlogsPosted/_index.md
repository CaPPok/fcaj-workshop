###  [BLOG 1 - AMAZON ATHENA - ANALYZING DATA ON S3 USING SQL WITHOUT CREATING A DATABASE](3.1-Blog1/)

This blog introduces Amazon Athena, a serverless service that allows you to directly query data (such as CSV, JSON, Parquet, ORC, Avro) stored on Amazon S3 using familiar SQL syntax. It outlines the specific steps to create reference tables and analyze data without needing to install or manage any database servers, while pointing out the advantages and important considerations to optimize query costs.

###  [BLOG 2 - AWS FAULT INJECTION SERVICE – PROACTIVELY INJECTING FAULTS TO TEST SYSTEM STABILITY](3.2-Blog2/)

This blog shares insights on Chaos Engineering via AWS Fault Injection Service (FIS) to evaluate the fault tolerance and availability of a system. It provides a guide on how to create controlled experiments based on predefined scenarios to proactively test whether the application infrastructure self-heals as expected.

###  [BLOG 3 - UNDERSTANDING AWS RESOURCE EXPLORER – SEARCHING AWS RESOURCES MORE EASILY](3.3-Blog3/)

This blog focuses on AWS Resource Explorer, a service that provides a unified interface to solve the difficulty of finding and managing AWS resources as a project expands. It explains how to set up an Index for the account and use flexible search syntaxes to quickly look up services (such as EC2, S3, Lambda) across multiple Regions without having to open each service individually.
