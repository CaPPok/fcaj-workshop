- Get familiar with the working environment, process, and members of the First Cloud AI Journey project.
- Understand office rules and regulations clearly.
- Successfully set up a personal AWS account and become proficient with AWS communication tools.
- Master the architecture and operation of core Cloud services.

### Week 1 Achievements:

* **Integrated into the environment:** Clearly understood the workflow and office regulations, and connected well with members of the First Cloud AI Journey project.
* **Mastered the tools:** Successfully set up AWS CLI on a personal machine (configured Access Key, Secret Key, Region) and became proficient with AWS Management Console.
* **Core infrastructure knowledge:**
  * Understood and applied secure access control (IAM) based on the principle of least privilege.
  * Successfully launched and connected to an EC2 virtual server via SSH.
  * Understood object storage with Amazon S3 and NoSQL databases with Amazon DynamoDB.
* **Expanded perspective with Amazon Athena:**
  * Understood the essence of Amazon Athena: a powerful serverless service that allows direct SQL queries on data stored in S3.
  * Recognized strong infrastructure-management benefits: no server provisioning required, compatibility with many data formats, and high usefulness for training-data analysis in Machine Learning workflows.
